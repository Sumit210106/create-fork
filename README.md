# create-template

> A simple CLI for scaffolding production-ready templates across multiple stacks.

## Templates

| Stack | Description |
|-------|-------------|
| **Next.js** | App Router + Supabase + Tailwind |
| **React (JS)** | Vite + Supabase + Tailwind |
| **React (TS)** | Vite + Supabase + Tailwind |

## Usage

```bash
npx create-template
```

Or if you prefer the old school way:

```bash
npm install -g create-template
create-template my-app
```


## Why?

I got tired of setting up the same stack over and over. Now I don't have to. Neither do you.

## Local Development

```bash
git clone https://github.com/yourusername/create-template
cd create-template
npm install
npm link
create-template
```
